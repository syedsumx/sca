# Cairn documentation

Cairn is a self-hosted platform for finding, trusting and governing data. It keeps a live metadata
graph of your data estate (datasets, dashboards, pipelines, owners, lineage) and adds data quality,
access governance, a data marketplace, context agents and an AI assistant on top.
