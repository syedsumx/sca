# はじめに

## サインイン

ブラウザで Cairn を開き、会社のアカウント（シングルサインオン）または管理者から受け取った認証情報でサインインします。
最初の管理者アカウントは `admin` です。

## 2 つの入口

* **ワークスペース**（左側のナビゲーションの *ワークスペース* グループ）は日常の画面です。**発見**（検索、ブックマーク、
  注目のアセット）、**データマーケットプレイス**（データプロダクト）、**申請**、**ガバナンススタジオ**、
  **コンテキスト受信トレイ**、**アシスタント** があります。それぞれナビゲーションに場所と固有のアドレスがあり、
  ブックマークや共有ができます。
* **カタログ** のページ（ホーム、用語集、ドメイン、データソース、設定）では、スチュワードと管理者がメタデータを整備し、
  取り込みを管理し、アクセスを設定します。

## データを探す

* 検索バーに入力します（`⌘K` または `/`）。結果には、認定、品質の状態、個人情報、鮮度といった信頼のシグナルが
  ひと目で表示されます。
* ファセットで絞り込みます：種類、プラットフォーム、ドメイン、認定、品質、機密度、オーナー。検索語とフィルターは
  URL に含まれるため、検索をリンクとして共有できます。
* 「発見」には、あなたのドメインで注目のもの、ブックマーク、最近見たアセット、おすすめのデータプロダクトが
  表示されます。

## アセットを理解する

アセットのページには、**概要**（説明、オーナー、業務用語、下流での利用）、**列**（型、分類、列があなたに対して
マスクされているか）、**ディスカッション**、**品質**、**リネージ**、**アクセス**、**履歴** のタブがあります。

## 共同作業

* 使うアセットを **ブックマーク** し、気になるアセットを **フォロー** します。品質インシデント、スキーマ変更、
  新しいコメントが通知されます。
* アセットや 1 つの列について **議論** します。`@名前` で同僚にメンションでき、返信とリアクションはスレッドに
  まとまります。

## 言語

画面右上の **質問** の隣で表示言語を選べます。選択はこのブラウザで有効です。選択しない場合、ブラウザの言語が
利用可能であればそれを使います：英語、ドイツ語、フランス語、スペイン語、日本語。
