# Documentation Cairn

Cairn est une plateforme auto-hébergée pour trouver les données, leur faire confiance et les gouverner. Elle
tient à jour un graphe de métadonnées de votre patrimoine de données (jeux de données, tableaux de bord,
pipelines, responsables, lignage) et y ajoute la qualité des données, la gouvernance des accès, une place de
marché de données, des agents de contexte et un assistant IA.
