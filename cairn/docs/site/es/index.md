# Documentación de Cairn

Cairn es una plataforma autoalojada para encontrar datos, confiar en ellos y gobernarlos. Mantiene un grafo de
metadatos actualizado de su patrimonio de datos (conjuntos de datos, paneles, pipelines, responsables, linaje) y
añade calidad de datos, gobierno del acceso, un mercado de datos, agentes de contexto y un asistente de IA.
